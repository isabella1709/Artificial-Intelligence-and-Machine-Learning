# 💡 Artificial Intelligence Exercises

This repository contains practical activities and notebooks developed for the Artificial Intelligence course. The exercises cover various topics and techniques in machine learning and data analysis, using Python and popular libraries such as `scikit-learn`, `pandas`, and `tensorflow`.

## 📚 Content

### ✅ Completed Activities

1. **Linear and Logistic Regression**  
   - Concepts of regression and classification using linear models.
   - Implementation with `scikit-learn`.

2. **Classification Problem**  
   - Supervised learning applied to labeled data.
   - Evaluation metrics and model performance analysis.

3. **Regression with Structured Data**  
   - Use of structured datasets to predict continuous outcomes.
   - Preprocessing, training, and evaluation of regression models.

4. **Time Series Forecasting**  
   - Forecasting future values based on historical time series data.
   - Models such as LSTM and other recurrent neural networks.

> This repository will be updated frequently with new exercises until the end of the semester.

## 🛠️ Technologies

- Python 3
- Jupyter Notebook
- scikit-learn
- pandas, numpy
- matplotlib, seaborn

## 📁 How to Run

1. Clone the repository:
```bash
git clone https://github.com/isabella1709/Artificial-Intelligence-and-Machine-Learning.git
cd ai-activities
```

2. Install dependencies:
```bash
pip install -r requirements.txt
```

3. Run notebooks:
```bash
jupyter notebook
```
